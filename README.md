# MEDICARE 🏥

A full-stack Hospital Management & Appointment Booking System built using the MERN stack.

## 🚀 Features

- Patient, Doctor, and Admin portals
- Secure authentication and role-based access
- Online appointment booking system
- Doctor slot management
- Payment integration for appointment booking
- Medical report upload and management
- Responsive UI for all devices
- RESTful API architecture

## 🛠️ Tech Stack

### Frontend
- React.js
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Other Tools & Services
- Clerk Authentication
- Stripe Payment Gateway
- Cloudinary
- REST APIs

## 📂 Project Structure

```bash
admin/
backend/
frontend/
```

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/riadhh-302005/medicare-project.git
```

### Install dependencies

```bash
cd frontend
npm install

cd ../backend
npm install
```

### Run the project

Frontend:
```bash
npm run dev
```

Backend:
```bash
npm start
```
